# Security Policy

## Supported Versions

WhiteRabbit is pre-alpha. Only the latest release and the default branch receive security fixes.

## Reporting a Vulnerability

Use GitHub private vulnerability reporting for the WhiteRabbit repository. Do not open a public issue containing exploit details, credentials, camera locations, plates, personal data, or footage.

Include:

- affected commit or release;
- impact and realistic abuse scenario;
- minimal reproduction using synthetic data;
- suggested mitigation if known.

Do not test against real deployments, third-party devices, public infrastructure, or data without explicit written authorization.

## Sensitive Data

The public repository must never contain production credentials, service-role keys, node tokens, signing keys, exact private camera locations, raw video, unredacted evidence, civilian plates, person identifiers, or raw chat transcripts.
